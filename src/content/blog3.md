# Networking Basics – HTTP, HTTPS và cách dữ liệu được truyền trên Internet
## 1. Giới thiệu

HTTP là giao thức cốt lõi của web. Mọi website và API đều hoạt động dựa trên HTTP hoặc HTTPS.

---

## 2. HTTP là gì?

HTTP (HyperText Transfer Protocol) là giao thức giao tiếp giữa client và server.

---

## 3. HTTP Request

Một HTTP Request gồm:
- Method
- URL
- Headers
- Body

Các method phổ biến:
- GET
- POST
- PUT
- DELETE

---

## 4. HTTP Response

Response gồm:
- Status Code
- Headers
- Body

Ví dụ:
- 200 OK
- 404 Not Found
- 500 Internal Server Error

---

## 5. HTTP là Stateless

Mỗi request độc lập, server không lưu trạng thái → sinh ra:
- Cookie
- Session
- Token

---

## 6. HTTPS là gì?

HTTPS là HTTP kết hợp SSL/TLS, giúp:
- Mã hóa dữ liệu
- Chống nghe lén
- Xác thực server

---

## 7. SSL/TLS (Tổng quan)

- Handshake
- Trao đổi khóa
- Mã hóa dữ liệu

---

## 8. Vì sao HTTPS là bắt buộc?

- Bảo mật
- Tăng độ tin cậy
- SEO tốt hơn
- Trình duyệt yêu cầu

---

## 9. Kết luận

HTTP và HTTPS là kiến thức nền tảng bắt buộc cho mọi web developer.
