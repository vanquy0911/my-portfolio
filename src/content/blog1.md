# Networking Basics – Mạng máy tính là gì và vì sao Developer cần hiểu?

## 1.Giới thiệu

Trong thời đại số hiện nay, gần như mọi ứng dụng, website hay hệ thống phần mềm đều hoạt động dựa trên Internet. Dù bạn là Frontend Developer, Backend Developer hay Fullstack Developer, bạn đều đang làm việc với các hệ thống có kết nối mạng.

Networking Basics không phải là kiến thức chỉ dành cho IT Support hay Network Engineer, mà là nền tảng quan trọng giúp developer hiểu cách dữ liệu di chuyển, cách client và server giao tiếp, cũng như cách các hệ thống hoạt động trong môi trường thực tế.

---

## 2. Mạng máy tính là gì?

Mạng máy tính (Computer Network) là tập hợp các thiết bị như máy tính, điện thoại, server, router… được kết nối với nhau nhằm trao đổi dữ liệu và chia sẻ tài nguyên.

Internet chính là một mạng máy tính khổng lồ kết nối hàng tỷ thiết bị trên toàn thế giới.

---

## 3. Các loại mạng phổ biến

### LAN (Local Area Network)
- Mạng nội bộ
- Phạm vi nhỏ
- Tốc độ cao

### WAN (Wide Area Network)
- Mạng diện rộng
- Internet là ví dụ điển hình

### MAN (Metropolitan Area Network)
- Mạng quy mô thành phố

---

## 4. Các thiết bị mạng cơ bản

### Router
- Định tuyến dữ liệu giữa các mạng

### Switch
- Kết nối các thiết bị trong cùng mạng

### Server
- Máy tính cung cấp dịch vụ

### Client
- Thiết bị người dùng

---

## 5. Mô hình Client – Server

Client gửi request → Server xử lý → Server trả response → Client hiển thị dữ liệu.

Đây là nền tảng của mọi ứng dụng web hiện đại.

---

## 6. Giao thức mạng là gì?

Giao thức mạng là các quy tắc giao tiếp giữa các thiết bị.

Một số giao thức phổ biến:
- HTTP / HTTPS
- TCP / IP
- FTP
- SMTP

---

## 7. Vì sao Developer cần hiểu Networking?

- Hiểu cách web hoạt động
- Debug lỗi hiệu quả
- Là nền tảng cho Backend & DevOps

---

## 8. Kết luận

Networking Basics giúp developer hiểu hệ thống thay vì chỉ viết code. Đây là kiến thức nền tảng nhưng cực kỳ quan trọng.
